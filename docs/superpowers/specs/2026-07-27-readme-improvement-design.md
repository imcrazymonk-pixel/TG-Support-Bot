# Дизайн улучшения README

## Суть
Улучшить существующий `README.md` для Telegram Support Bot без поломки существующего контента. Четыре изменения: бейджи, mermaid-диаграмма, детализированные фичи, секция разработки.

## Изменения

### 1. Бейджи
Добавить `<div align="center">` после лого с бейджами: Node.js (20), TypeScript, grammY, Docker, MIT. Использовать `https://img.shields.io/` статичные бейджи.

### 2. Mermaid sequence-диаграмма
Заменить маркированный список в «Как это работает» на блок `sequenceDiagram` mermaid. Шаги те же — просто визуализация.

### 3. Детализированные фичи
Расширить секцию «Возможности» с маркированного списка до структурированных описаний:
- **Spam protection**: 10 сообщений / 20 сек окно → мут на 60 сек
- **Inactivity cleanup**: 7 дней бездействия → предупреждение оператору с кнопкой очистки
- **Privacy cleanup**: прозрачное уведомление при пересоздании темы
- **`/myid`**: показать Telegram ID

### 4. Секция «Разработка»
Новая секция с:
- Локальный запуск: `npm run dev`
- Сборка: `npm run build`
- Тесты: `npm test`
- Примечание про структуру проекта
